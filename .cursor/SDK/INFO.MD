Web SDK v5.13 уже доступен! 🚀 
Мы рады объявить о выпуске MobileMed.ai Web SDK v5.13, доступного с 13 июля 2026 года. Этот релиз включает новые улучшения платформы и функциональные возможности, которые помогут вам проводить ещё более качественную оценку жизненно важных показателей. 
✨ Что нового? 
✅ Система рекомендаций по положению пользователя (PGS) 
Теперь SDK предоставляет доступ к новой системе Posture Guidance System (PGS) для сессий измерения по лицу. PGS передаёт покадровую информацию о положении пользователя и устройства, включая: 
• Положение и выравнивание лица 
• Угол наклона устройства и расстояние до него 
• Условия освещения 
Это позволяет приложениям давать пользователям рекомендации до начала измерения, а также во время отображения предварительного изображения с камеры. 
✅ Публикация Web SDK через JFrog Artifactory 
Артефакты Web SDK теперь публикуются через JFrog Artifactory. 
Инструкции по интеграции с Artifactory приведены в Руководстве по интеграции Web SDK. 
✅ Новый API PGS 
Новый API для определения положения — CaptureData — охватывает все параметры, связанные с корректностью изображения и положением устройства, по следующим категориям: 
• Лицо 
• Устройство 
• Окружающая среда 
Полная документация API Web SDK доступна на портале разработчиков. 
⚡ Почему стоит обновиться? 
✅ Более эффективные рекомендации для пользователя до и во время измерения 
✅ Улучшенная обратная связь по положению и выравниванию лица, расстоянию, углу наклона устройства и освещению 
✅ Обновлённый способ распространения Web SDK через JFrog Artifactory 
✅ Единый API для получения информации о корректности изображения, положении пользователя и устройства 
📌 Поддерживаемые версии SDK 
В настоящее время мы обеспечиваем полную поддержку следующих версий Web SDK: 
• Web SDK 5.13 
• Web SDK 5.11 
• Web SDK 5.9 
Обратите внимание: после выхода следующей версии Web SDK, предварительно запланированной на IV квартал 2026 года, поддержка Web SDK 5.9 будет прекращена.
